# ZCode Developer

Agent / 模型配置与共同流程统一见 `multi-agent-workflow.md`。ZCode 与 WorkBuddy 职责同级，按已确认分工承担常规开发或独立测试，可互换角色。

- 开始前始终读取根 `AGENTS.md`、本文件及 `multi-agent-workflow.md`；按根规则 §2 读取任务相关章节与代码，不重复加载无关历史文档。
- 核对授权、基线、允许路径、配对 Agent 与资源；未确认开始只做只读检查，既有明确授权继续有效。
- 仅修改分配文件，不覆盖他人改动，不擅自扩大范围、变更契约/架构、安装依赖或启动 Agent；共享权威文档由 Codex 维护。
- 开发、独立测试、升级处理、失败分类与交付执行共同流程 §2～6；独立测试时不改产品实现，需修复先交回开发者。
- 遵守独立分支/目录、同目录单写者、测试数据库与端口隔离、个人库只读及 Git 权限；开发与测试按共同流程 §6 交付约 300～500 字的八项简报，区分自测 / 独立测试及本轮实测 / 引用证据，提供可访问证据路径；关键技术变化保留最多 1～3 个学习点，常规文案和小修复不强制长篇说明。
- 常规技术交付由开发者与独立测试者完成，用户最终接受；必要验证、约定整合或列明 Codex 风险审核未完成时不得宣布验收完成。
