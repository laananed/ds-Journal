## 1. 目标与阶段入口

Stage 3 实现「AI 陪伴写作 + 单篇/多篇复盘 + Insight 辅助提炼」，继续本地单用户 Web 与既有三类文件、Folder、普通搜索、回收箱和 Markdown 阅读。

阶段路线当前以本节为唯一来源：Stage 1/1.5 已完成；Stage 2 为基础记录版，技术验收记录见 `stage2-tasks.md` §20，用户最终接受与所列独立复核仍需核实；Stage 3 为 AI 陪伴写作、复盘与 Insight 辅助提炼，具体 Task 授权与执行见 `stage3-tasks.md` §17；Stage 4 完整 UI 重构；Stage 5 云端部署；Stage 6 AI 增强（RAG、语义去重、长期记忆、情绪趋势等）。后续阶段只登记方向，不编制或实施其功能；历史路线由本轮路线替代。

进入 Stage 3 开发前检查 Stage 2 实际集成基线、接受状态及遗留问题。规划可以完成，不能以规划宣布 Stage 2 已整体验收。Stage 2 保留行为除本文明确升级的自动保存、结构化 AI 内容及关联 API 外继续有效。

## 2. 自动保存

- Inbox（含 Daily）、Journal、Insight 新建与编辑都自动保存；有效输入停止约 800ms 后提交，并保留立即保存入口。显示「未保存 / 保存中 / 已保存 / 保存失败 / 冲突」。已保存必须代表数据库已提交，而非浏览器缓存。
- 标题、正文、可编辑日期和 Folder 同次原子保存；空白正文、超长输入不提交并保留输入。不创建空文件或空 Daily。Daily 仍采用本地 04:00 业务日期，打开的新建草稿跨 04:00 不偷偷改变其日期。
- 切换文件、模块、列表、内部链接或复盘前先完成有效待保存写入；失败时停留并允许重试，用户明确放弃才离开。保存中的连续输入不被早一批响应覆盖；写成功但列表刷新失败只重试读取。
- 关闭、刷新或重新打开后保留所有已成功保存内容。未成功提交的最后几次输入不能承诺在强制关闭、断电时保存；有未保存输入使用浏览器离开提示。不引入本地日记副本、离线队列或同步系统。
- 多标签页编辑发生冲突时保留当前草稿与服务器版本供用户选择，不自动覆盖、自动合并或后台不断重试。

## 3. 陪伴写作与增量

- 仅 Journal/Inbox 提供局部互动，点击才调用 AI，不逐键调用。首次读取已有用户正文；以后默认只读上次成功分析以来新增的用户文本。完整总结不会把模式永久变成全文模式。
- 提问栏允许没有新增正文时继续对话；问题是独立对话信息，不伪装成日记事实。无新增、无有效问题时显示 **「要我分析啥啊？」**，不请求模型、不消耗 Token、不插入蓝块。
- 成功分析是回复已持久化并附着到对应源文本；失败、超时、冲突或未落库不推进检查点。分析前的自动保存必须成功。
- 编辑或删除已分析旧文字属于修订：明确提示「之前的文字有改动，本次从改动处重新分析」，读取从首个差异处起的当前用户文本，不把旧全文静默重发；全部删除且无问题不调用。详细算法归架构文档。
- 普通新增分析不夹带旧全文或旧总结；主动提问可带有限近期对话上下文，若需要整篇理解，用户明确选择完整复盘。不是长期记忆。
- 回复紧接本次调用的用户文本末尾，后续在下方继续写。保留普通 textarea，采用多个原生文本区与独立 AI 块交错排列；不是在同一个 textarea 内着色。
- AI 块蓝色文字、左侧蓝色竖线，成功后自动保存；支持右键、移动端长按或明确菜单删除，键盘可用。删除蓝块不撤销已发生的分析或 Token，不自动重新分析。
- 推荐最小并发行为：同一文件局部调用期间短暂锁定该文件编辑与导航，显示处理中（最长 90 秒）；其他标签页仍可能写入，后端必须检查源版本。此限制减少错误插入与自动合并成本，不是全软件冻结。

## 4. 模型、联网与风格

- 仅 DeepSeek 官方 API，模型固定默认 `deepseek-flash`（V4.1 Flash）；不提供供应商切换或 Agent 框架。推荐非思考、非流式请求，以降低延迟、Token 与失败处理复杂度。
- 方案 A：Function Calling + 独立搜索 API，不引入 MCP。设置默认联网开启，模型只有需要外部资料时才发起搜索；关闭后不提供搜索工具，也不能以其他途径访问外部检索。
- 推荐 Brave Search 的普通 Web Search；只检索公开主题与必要关键词，不默认发送日记全文、长段原文、身份信息或自定义私密提示词。无法安全形成检索词时跳过搜索并说明。搜索未配置或失败时说明「未联网」，不伪造资料或引用。
- 有外部事实依据时附可点击来源；网页/摘要是参考数据，不能当作系统指令。只读取搜索结果摘要，本期不抓取任意网页、图片或附件。
- 回复简短、自然、口语化、活泼调皮，像陪伴写作的小朋友；偏向启发与情绪支持，避免机械套话和居高临下。局部回复通常 1～3 句、一个自然追问，信息不足可以不提问；不强制每次相同格式。
- 示例：「咦，你前面说想休息，后面又把活接回来了。是怕别人失望，还是做完会更安心一点？」避免「作为人工智能」「建议制定 SMART 计划」或无依据的人格标签。

## 5. 完整复盘与保存

- 单篇支持 Journal/Inbox；多篇选择有效 Journal/Inbox，可跨两类。最多 **7 个不同业务日期、15 个去重文件**，不是连续七天，也不是单类各 15 篇。Journal 使用 journal_date，Inbox 使用 inbox_date；Insight 无业务日期，不是复盘输入。重复 `(type,id)` 为非法输入，软删或缺失源拒绝调用。
- 复盘读取所选文件全部用户正文，排除既有 AI 局部回复、AI 总结；标题、日期、来源身份仅作背景。人工写入的旧总结无法自动识别，视为旧用户正文，不追溯猜测。
- 内容包括：事实；简短情绪推测及原文依据；可能解释；默认三个角度（事件与情绪、选择与行为、认知与关系）；行为与思考逻辑链；自然追问；可选 Insight 草稿。缺少依据的角度可写「暂时看不出来」，不凑结论。推测与事实明确区分，引用标记对应具体源文件。
- 可判断具体行为，不默认判断人格、预测未来或提供行动优化方案；没有证据不强行推断。用户明确追问行为建议可回应问题，但默认复盘模板不加入行动清单，不扩展为教练系统或心理诊断。
- 先生成持久化预览，用户可修改；**完整总结只确认一次**，确认后直接事务保存，无逐段、逐观点再确认。取消或离开预览不写原文件，也不创建空目标。
- 单篇 Journal：在原文底部以 `---` 分隔追加 AI 总结，保留来源标记；用户可修改总结块，修改后仍保留 AI 来源身份。重复做复盘可形成新总结，不自动覆盖旧总结。
- Inbox 单篇/完整复盘、多篇综合复盘：在 Journal 新建文件，不转换、删除或移动源 Inbox；默认日期为发起复盘时本地 04:00 业务日期，默认无 Folder，保存前可改标题、日期、Folder。同一次预览重复确认只产生一个结果。
- 生成时记录源快照，保存前核对源用户内容、标题、业务日期、Folder/删除状态；源变更返回冲突并保留预览，不把过期分析当最新总结。Token 已消耗不会退回。一次保存最多 50,000 Unicode 码点的正文投影，超限时先调整预览或选择保存为新 Journal（单篇 Journal 的可选替代），不截断原文。

## 6. Insight 辅助提炼

一个观点对应一份 Insight，可引用多个事实/多个源文件支持；一次复盘可返回零份或多份独立草稿。不将多个观点强行塞进一份，不强制从每次复盘提炼观点。
AI 只提供草稿，用户自行修改、补事实、添加或放弃；使用现有 Insight 管理与自动保存。在用户主动选择「添加为 Insight」后进入编辑，不因查看预览产生文件。草稿正文含观点、依据和普通来源文本；不建事实关系图或强外键引用。
相似内容由用户复用现有普通搜索查看，不做语义去重、合并、评分或自动阻止添加。源删除后已有总结/Insight 可保留其文本依据，并提示源不可用。

## 7. 设置、Token 与数据保护

- 设置持久保存自定义 AI 提示词与联网开关，重启后仍有效。提示词补充语气/角度，不覆盖正文与 AI 区分、搜索隐私、事实边界及数据安全规则。进行中的调用使用发起时设置快照。
- Key 仅在后端进程环境或忽略的 `.env`，不进前端、数据库设置、URL、Git、日志和报错。设置仅显示已配置状态；本期不在浏览器录入 Key。
- 统计全软件累计模型 Token；文件中可查看本次及历史调用消耗。一次功能调用包含搜索前/后所有模型子请求，缓存输入不得重复计入。删除文件或蓝块不减少累计量，多篇调用在各源文件显示同一个调用 ID，全局仅计一次。
- 使用官方返回 usage；未收到 usage 的请求标记未知，显示「已确认 Token + 未知调用数」，不得显示成零或宣称绝对精确账单。独立搜索请求数另计，不混为模型 Token。本期不做充值、人民币账单或重置累计。
- 所有写入有版本防覆盖，AI 功能请求有幂等键；关闭页面不保证取消上游计费，重新打开先查询请求状态，禁止静默重复付费。

## 8. Non-goals

不做完整 UI 重构、云部署、账号/登录/同步、Android、离线草稿系统、操作历史/版本恢复、富文本编辑器、任意块拖动、网页爬虫、文件上传、RAG/Embedding/向量库、语义相似、长期记忆、情绪趋势、人格画像、未来预测、自动行动计划、MCP、多模型、后台任务队列或主动定时 AI。仅添加本期可用的 AI/设置/复盘入口与必要蓝块样式。
